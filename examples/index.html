pretext-kit examples

pretext-kit sizes text exactly before it paints: font sizes that fit a box, widths that balance lines, clamped and middle-truncated text, list heights. It is built on Pretext and is not part of it. Pretext's own demos already show chat bubbles, ellipsis and a virtual chat list; these pages show what the kit adds, each next to the same UI in fixed-size CSS.

How these pages are built

  • They follow Pretext's demo rules: the model owns every measured value and the painter writes it inline; nothing corrects what the kit reports.
  • Fonts come from fontFromStyle(getComputedStyle(el)). The screens use Inter, a web font the local server sends 1.5 s late, so you can see watchFonts lay the page out again when it lands.
  • npm run examples builds them; npm run examples:serve serves them on http://localhost:4173.
