pretext-kit examples

Text size

An app-wide text-size setting, like the one in iOS, Android and most desktop apps, from 0.8× to 1.5×. A text-size setting is a different font size in CSS px, so the kit prepares each size it needs (prepareSizes keeps them) and fits every label again within the scaled range. The fixed-size CSS scales its fonts by the same factor and keeps its boxes.

Inter, a web font, is still loading: until it arrives, both screens measure and paint the fallback, Helvetica Neue.

Zoom is not text size

  • Browser and Electron zoom (Cmd/Ctrl +) changes device pixels per CSS px, not CSS px, so nothing here needs correcting for it: the sweep in verify/RESULTS.md found no kit mismatch at Playwright deviceScaleFactor 1, 1.25 and 2 in Chromium, WebKit and Firefox on macOS (the 1.25 and 2 runs at a 4px width step), with the same counts at 1.25 and 2. That is emulation on one OS, not proof for Windows or Linux font rendering; see RESULTS.md.
  • A text-size setting changes CSS px, so it is a new font: prepare per size. The kit's fit ranges scale with the setting (toolbar 11–14px becomes 14–18px at 1.25×) and line heights stay whole pixels.
  • Boxes keep their padding; only text scales. Icons scale with the text they sit next to.
