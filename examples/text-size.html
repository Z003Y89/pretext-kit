pretext-kit examples

Text size

An app-wide text-size setting, like the one in iOS, Android and most desktop apps, from 0.8× to 1.5×. The kit honours the size the reader asked for: it reflows first (content-width buttons, icon-only buttons, a second line, a badge on its own row) and shrinks text only within a small band, never below 90% of the requested size. That is a trade-off: shrinking more would keep the layout tighter, but text that ignores a text-size setting fails the reader it is for (cf. WCAG 1.4.4, Resize text). The best-effort CSS side scales its fonts by the same factor and wraps.

What CSS can't match here

  • One shared size for a row that holds as text grows: the toolbar and the buttons switch layout (shared size, icon-only, two lines) at the exact text size where the current one stops fitting.
  • Badges that fit at the reader's size, moving under the case row rather than being cut.
  • Every height before render, for any text size: a text-size setting is a new font size, so the kit prepares each size it needs once (prepareSizes keeps them).

Inter, a web font, is still loading: until it arrives, both sides measure and paint the fallback, Helvetica Neue.

Zoom is not text size

  • Browser and Electron zoom (Cmd/Ctrl +) changes device pixels per CSS px, not CSS px, so nothing here needs correcting for it: the sweep in verify/RESULTS.md found no kit mismatch at Playwright deviceScaleFactor 1, 1.25 and 2 in Chromium, WebKit and Firefox on macOS (the 1.25 and 2 runs at a 4px width step), with the same counts at 1.25 and 2. That is emulation on one OS, not proof for Windows or Linux font rendering; see RESULTS.md.
  • A text-size setting changes CSS px, so it is a new font: prepare per size. The kit's fit ranges scale with the setting (the toolbar's 13–14px becomes 16–18px at 1.25×) and line heights stay whole pixels.
  • Titles, bodies and card heights: CSS handles these equally well here (balance, line-clamp, auto heights); the kit adds the numbers before render.
  • Boxes keep their padding; only text scales. Icons scale with the text they sit next to.
