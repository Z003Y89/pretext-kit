pretext-kit examples

Languages

The same screen in English, German and French, at a phone-to-tablet width. German compounds („Tagesabschlussbericht“, „Zahlungspflichtig abonnieren“) and long French labels („Enregistrer les modifications“) are what break layouts. Both sides get the same strings and the same hyphenation policy: no hyphens in badges or bodies; German labels carry soft hyphens written by hand at their compound joints („Tages·abschluss·bericht“, „Zahlungs·pflichtig“; a dictionary would pick syllables such as „Tagesab-schluss…“), which the kit uses only when a word is wider than the room left for it and CSS uses whenever it wraps; in titles, the kit hyphenates only a word wider than the card (with soft hyphens put in at build time by the hyphen package's TeX patterns), and the CSS side uses hyphens: auto.

What CSS can't match here

  • Labels that fit without hyphens: each language's toolbar and buttons get their own shared size and layout, chosen by measuring, instead of wrapping the row; a label breaks at a compound joint only when one of its words is wider than the room.
  • Hyphenation only where it's needed: the kit knows which title word is wider than the card. CSS hyphens: auto follows each browser's dictionary, which differs per engine.
  • Badges that fit in every language, at one size per list.

Inter, a web font, is still loading: until it arrives, both sides measure and paint the fallback, Helvetica Neue.

Notes

  • Each browser's hyphens: auto dictionary differs (and some have none for a language), so no measurer can know where it will break. Soft hyphens (U+00AD) put in once give Pretext and every engine the same break opportunities; the verify sweep runs German and French hyphenated this way through every helper (verify/RESULTS.md).
  • Titles, bodies and card heights: CSS handles these equally well for display.
  • File names, case numbers and names are never hyphenated.
