Languages

The same screen in English, German and French, at a phone-to-tablet width. German compounds („Tagesabschlussbericht“, „Zahlungspflichtig abonnieren“) and long French labels („Enregistrer les modifications“) are what break fixed-size layouts. The kit side's German and French were hyphenated once, at build time, by the hyphen package (TeX patterns), and are measured and painted with hyphens: manual; the CSS side uses hyphens: auto with each block's lang, which depends on the browser's dictionaries.

Inter, a web font, is still loading: until it arrives, both screens measure and paint the fallback, Helvetica Neue.

Why soft hyphens and not hyphens: auto

  • Each browser's hyphens: auto dictionary differs (and some have none for a language), so no measuring library can know where it will break. Soft hyphens (U+00AD) put in once give Pretext and every engine the same break opportunities.
  • The verify sweep runs German and French corpora hyphenated this way through every helper; see verify/RESULTS.md for the counts per browser.
  • File names, case numbers and names are never hyphenated.
